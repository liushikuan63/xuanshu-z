# 测试与质量门禁

## 必跑检查

```bash
npm run typecheck
npm test
npm run verify-citation
npm run verify-playbook
npm run kb:lint
npm run build:web
```

`npm run check` 聚合明文凭据扫描、类型检查、全量测试、引文校验和路径卡校验。语料检查因扫描量较大而独立执行；任何一项失败都不应发布。

## 覆盖重点

- 历法边界：子时换日、节气换月、真太阳时和缺时辰降级。
- 八术回归：盘面字段、卦名、阴阳遁、四课三传、藏干层级和时辰映射。
- 配置迁移：旧本地存储缺字段、非法 JSON、存储不可用。
- 引文：`segId`、章节、书名和证据等级可定位。
- 语料：ID 唯一、派生文本、UTF-16 `charRange`、乱码、网页页眉/页脚污染。
- 响应式：三类视口无横向溢出、重叠或不可达按钮。
- 构建：Web 生产包、Capacitor 同步和 Android Gradle APK。

## 手动界面验收

自动测试不能替代视觉验收。每次调整共享 UI 后应记录三个视口的根宽度、主内容偏移、侧栏/底栏显示状态，并检查浏览器控制台渲染错误。书阁需额外检查七类状态标签、来源链接、相关原典跳转和全文阅读。
