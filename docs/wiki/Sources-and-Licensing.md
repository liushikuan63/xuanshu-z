# 来源与授权

## 基本规则

1. 古籍原作进入公有领域，不自动使现代点校、标点、OCR、数据库编排或网站页面进入公有领域。
2. 每部书的授权和来源以 `data/.kb/books/<id>/meta.json` 为准。
3. 维基文库来源应同时注明原作公有领域与电子文本 `CC BY-SA 4.0`。
4. 授权不明确的现代或民国作品只保留书目信息和外链，不复制全文。
5. 来源页面可用于考据，不等于获得再分发许可。

## 置信等级

| 等级 | 用途 |
|---|---|
| A | 可核验底本或可信开放电子文本 |
| B | 文本可读但作者、版本或转录可靠性仍有争议 |
| C | 间接资料或需要进一步校勘 |
| D | 仅用于低置信补充，不得支撑关键断语 |
| E | AI 或未核验解释，必须与原典分区 |

## 已核验新增来源

- 维基文库《苌氏武技书》：六卷正文，原作公有领域，电子文本 CC BY-SA 4.0。
- 维基文库《太极拳论》：页面标记正文完整但来源可靠性未定，按 B 级导入。
- 维基文库《养性延命录》：正统道藏本全文，含五禽戏早期具体记载。
- Chinese Religious Text Authority：用于核对《万寿仙书》1832 年木刻本与书目信息，不复制其页面内容。
- 识典古籍：用于核对叶九升《地理大成》的题名、辑者、序和目录；正文待逐卷许可与 OCR 校验。

## 仓库代码

仓库目前没有统一代码许可证。公开托管只代表代码可见，不自动授予复制、修改、再发布或商业使用权。仓库所有者选择许可证后，应在根目录增加 `LICENSE`，并再次检查它与所有内置语料许可是否兼容。
