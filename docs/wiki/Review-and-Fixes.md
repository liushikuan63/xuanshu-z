# 代码审查与修复

本页记录 2026-09-05 全仓审查发现的问题、处理边界和回归证据。它不是发布宣传，而是后续维护者定位设计决定的入口。

## 命令与构建

| 问题 | 影响 | 修复 |
|---|---|---|
| 根命令依赖不存在的脚本和参数转发 | `test`、`typecheck` 等入口不可稳定复用 | 统一由 `scripts/run.mjs` 解析命令、转发参数和传播退出码 |
| 移动脚本忽略子进程失败 | Web 或 Gradle 失败后仍可能继续 | 子进程启动错误和非零退出码立即抛出 |
| 古籍全部进入首屏主包 | 浏览器和 WebView 首次解析负担过大 | 逐书动态导入，React、引擎、共享 UI 和语料分包 |

## 排盘与领域模型

修复范围包括八字性别与大运元组、十神藏干层级、梅花互错卦映射、奇门阴阳遁与界面字段、小六壬时辰序列、六爻字段、金口诀证据、合婚字段和真太阳时经纬度传递。每个算法缺陷均以确定性输入补充回归测试，避免只修界面显示。

## 状态与隐私

- 旧版 `localStorage` 缺失字段时按默认配置深度合并，非法 JSON 和存储不可用时安全降级。
- AI 密钥只保存在当前页面内存，不再写入浏览器持久存储。
- 移除代码中硬编码的第三方 API Key；AI 默认关闭，只有用户显式启用并输入自己的会话内 Key 后才可发起请求。
- 路由参数先校验再进入视图，避免未知页面导致空白状态。

## 知识库

- 修复 16 部语料中的可逆乱码，共恢复 3,526 行；无法确定的字符以 `□` 保留缺口，不臆造原文。
- 语料检查覆盖唯一 ID、派生字段、UTF-16 字符区间、乱码和网页导航污染。
- 新增《苌氏武技书》《太极拳论》《养性延命录》可定位文本，并保存来源、许可说明和抓取日期。
- 原典不存世、仅有扫描或受现代版权保护的条目不伪装成全文，书阁显示明确状态和现存信息。

## 多端界面

共享样式按三类稳定布局处理：手机使用底部导航并计入安全区，平板使用 62px 紧凑侧栏，桌面使用 216px 完整侧栏。固定格式盘面设置响应式约束；长文本允许换行，主内容不产生横向溢出。

## 验收

发布前至少执行：

```bash
npm run check
npm run kb:lint
npm run build:web
node scripts/mobile-emulator.mjs sync
```

同时在 390x844、768x1024、1440x900 三类视口检查主导航、书阁、排盘和设置页。APK 还需通过 Android `apksigner verify`；debug 签名包只用于测试分发，不作为正式商店版本。
