# 知识库与书目状态

## 目录结构

```text
data/.kb/books/
  manifest.json
  <canonical_id>/
    meta.json
    corpus.jsonl
```

`meta.json` 记录底本、作者、来源、许可、采集日期、段数和置信等级。`corpus.jsonl` 每行一个独立 JSON 对象，规范见 `docs/corpus-spec.md`。

## 七类状态

| 状态 | 含义 | 可进入阅读器 |
|---|---|---|
| `full` | 已导入可检索正文 | 是 |
| `related` | 条目非单一定本或原典亡佚，内置相关存世原典 | 是 |
| `scan` | 有馆藏或扫描，尚未可靠转录 | 否 |
| `lost` | 书目有载但原典亡佚 | 否 |
| `oral` | 口传或近现代整理，无统一公版底本 | 否 |
| `restricted` | 现代作品或授权边界不明 | 否 |
| `uncertain` | 题名、作者、年代或底本待考 | 否 |

`hasCorpus` 只表示本地是否有可读语料；`corpusStatus` 才解释它是本书全文还是相关原典。

## 导入流程

1. 联网核验书名、作者、卷数、底本和许可。
2. 浏览器打开公开来源并确认正文范围。
3. `scripts/receive-browser-text.mjs` 只在 `127.0.0.1` 单次接收文本后退出。
4. `scripts/import-browser-corpus.mjs` 使用正文起止锚点清理、繁简转换、切段并更新清单。
5. 运行 `npm run kb:lint`，并抽查首段、末段、章节列表和来源元数据。

禁止把搜索摘要、生成式文本、无法确认授权的现代全文或未清洗 OCR 直接放入语料。
