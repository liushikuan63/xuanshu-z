# 玄枢 · 八术综合占卜工作台 —— 需求文档

> 版本：v1.0（2026-09-05 审查修订）　适用范围：玄枢生产仓库 `xuanshu-z`（monorepo）。本文与本仓库共存：Web(`apps/web`)、桌面(`apps/desktop`)、Android/移动(`apps/mobile`，Capacitor) 三端同一套 `packages/*` 代码。
> 修订记录：v1.0 同步当前语料规模与七级书目状态；v0.9 增加「精批白话一致性」硬约束与「出生地省市筛选」需求，并附与参考项目 `xuanshu`（旧版单页仓库）的对比结论。

---

## 1. 产品定位

**本地优先、可引证的八术综合占卜工作台**：八字 / 六爻纳甲 / 梅花易数 / 紫微斗数 / 奇门遁甲（时家+日家、转盘+飞盘、拆补/置闰/茅山）/ 大六壬 / 小六壬 / 金口诀八大体系「确定性排盘 + 开放性解释 + 路径可学习」三位一体。

- 排盘层：纯函数、确定性、可复现（configHash 唯一决定盘面）。
- 解释层：每条断语带 `ruleId` 与五级（A–E）出处角标，点击回链原典段落。
- 学习层：术语白话、精批白话详解、断事路径卡、排盘分步教学、术语 800+ 词库。

## 2. 用户与场景

| 群体 | 典型诉求 |
|---|---|
| 玄学入门者 | 看懂盘面：每格要点可点、白话解释成段、术语即点即查 |
| 日常问事者 | 六步向导选事项→起卦→出盘，问事类别影响取用神与解释侧重 |
| 进阶研究者 | 古籍原文对照、路径卡九段法、case 应验回标与校准 |
| 异地/旅行用户 | 真太阳时按出生地/起卦地经度换算（本轮扩展覆盖到全国地级市） |

## 3. 功能需求

### 3.1 起卦与排盘（八术）
- FR-01 六步向导：选事项（14 类）→ 细化问法（质量提示）→ 术数与配置 → 起卦/输入 → 出盘与解释 → 记录标注。
- FR-02 专业排盘：自选术数/排法（时间、报数、摇卦、起盘方式），支持 hash 直达（`#/pro?art=…`、`#/cast?art=…&cat=…`）。
- FR-03 八术全量：八字（流月→流日→流时逐层展开、一生趋势 SVG、**流年/流月/流日/流时四柱对照**（当前时刻四柱＋与命局刑冲害破合·十神·藏干·纳音））、六爻、梅花、紫微（12 宫 4×4 + 大限流年时间线）、奇门（时/日、转/飞、拆补/置闰/茅山，四害自动标注）、六壬（天地盘 12 宫、四课三传）、小六壬（六宫横条）、金口诀（四位+五动+三动）。
- FR-04 精批白话详解（`jingPiFor`，8 术+日家各一版）：总纲 + 分段白话 + 开运 tips；八字含称骨、六亲、财富、大运节奏等九段。
- FR-05 本题问事·专断：按所选类别从跨系统断事表匹配对应断语嵌入精批卡，可展开「八术各看什么」对照。

### 3.2 解释与学习
- FR-06 术语库 800+ 白话词条，阅读器悬浮注、排盘页即点即查。
- FR-07 断事路径卡 28 张（9 段结构），覆盖全部 14 类事项。
- FR-08 古籍书阁 86 部／32,673 段：BM25 检索、五级可信度、原文/白话对照、深链高亮；目录条目另以全文、相关原典、扫描待校、原典亡佚、口传整理、版权受限和底本待考七种状态据实标注。
- FR-09 年度运程合参、应期真实日期引擎（逢值/逢冲/逢合/填实给具体公历日期）、时间信息条（三历对照+节气+建除+黑黄道+宜忌+神位+真太阳时换算）。

### 3.3 记录与校准
- FR-10 案例本：每术 99 条配额（90 预警）、应验/未应验回标、去重、导出 JSON/CSV/MD。
- FR-11 校准：只校准解释习惯，绝不回写排盘层。

### 3.4 出生地（真太阳时）—— 本轮增强
- FR-12 城市表扩充：覆盖全国 34 个省级行政区（直辖市/自治区/特别行政区），共 **323 个城市**，每城带东经经度，供真太阳时换算。
- FR-13 **省份筛选**：出生地/起卦地区选择器改为「省份 + 城市」二级联动（`全部省份` 兜底全表），省级列表 `CITY_PROVINCES`、按省取城 `citiesOfProvince(p)`。
- FR-14 兼容保留：自定义经度输入兜底、「未设置（用北京时间）」默认态；经度→城市名反查（`cityNameOf`，±0.15°）保持可用。
- FR-15 三处入口同步升级：向导第 4 步（出生地）、时间信息条（出生/起卦地区）、设置页真太阳时开关与经度。
- FR-16 数据模型统一：`CITY_LONGS` 从 `{n,lng}` 升级为 `{n,lng,p}`（p=省/直辖市/自治区/特别行政区），同一份表供输入区、时间信息条、设置页复用。

### 3.5 多端与离线
- FR-17 Android（Capacitor WebView）与桌面（Electron）复用同一 Web 构建产物；移动端流程固化于 `scripts/mobile-emulator.mjs`（Google 模拟器 / LDPlayer14 双通道）。
- FR-18 离线可用：语料随构建内置，无网络依赖（AI 精解默认关闭）。

## 4. 非功能需求 / 硬约束

### 4.1 排盘确定性（已有约定，沿用）
- NFR-01 排盘纯函数：无 `Date.now`/IO；盘面由 `configHash`（16 位稳定指纹）+ 完整配置快照唯一决定。
- NFR-02 时辰缺失降级：奇门/大六壬/金口诀阻断不编盘；八字降三柱并禁用需时柱规则并给出明确提示。

### 4.2 解释文本一致性 —— 本轮新增硬约束（源自线上缺陷「忌=。行」与「六亲批注/白话对不上」）
- NFR-03 **批注与白话同源**：白话段必须由与批注相同的计算数据/分布推导，禁止写死与盘面断言相悖的结论（如命局"正印不透"却白话"正印透母慈"）。
- NFR-04 **空值不得泄漏**：任何模板拼接空数组/空字段时，紧跟标点前必须有兜底值（惯例用 `—`）；全盘禁止出现 `：。/=。` 之类空值泄漏（正文与标题均查）；**禁用重复标点**（`。；`、`。。` 等紧邻，如配偶句号与子女分号衔接、称骨诗文自带句号后再拼「。白话」）。
- NFR-05 **回归护栏**：`tests/jingpi-audit.test.ts` 多样本（跨四季生日 × 9 术，含日家）扫描空值泄漏与重复标点；`tests/jingpi.test.ts` 校验六亲批注/白话口径一致与 `忌=` 兜底。
- NFR-06 引用契约（R11/R12）：八术规则输出引用非空（A/B/C 级）；引擎引用与语料对账由 `verify-citation` 脚本校验。

### 4.3 内部标识零泄露
- NFR-07 面向用户界面不得出现内部标识（`Iter38`、`configHash`、引擎版本号、ruleId 裸串等）；遗留泄露点已清零并以换页巡检固化为流程。

### 4.4 可访问性与构建基线
- NFR-08 主题对比度 WCAG AA（宣纸/朱砂/黛青 + 暗色 + 高对比）。
- NFR-09 交付基线：`vitest` 全量 **99+** 用例通过；`vite build` **0 警告**；移动端实机关键链路（向导起盘、精批卡、专断弹窗、出生地省市联动、真太阳时、时间校对）CDP 驱动验证无致命错误。
- NFR-10 **系统时间校准与起局时刻手动调整**：设备时间可能不准（快/慢），必须允许在校对条（±1/±5/±30 分与复位）对正并持久化于 `config.calendar.timeOffsetMin`；所有「以当前时刻起局」的术（奇门/六壬/金口/小六壬/六爻时间卦/梅花时间卦）在起卦界面提供**可直接编辑的起局时刻**（年/月/日/时/分，默认=校准后的当前时刻）+「取当前（校准后）时刻」一键刷新，起卦严格按该时刻排盘；八字/紫微仍用用户填写的出生时间。

### 4.5 代码分层与包边界
- `core`（确定性）→ `intake`/`answer`/`knowledge`/`reader`/`ledger`/`ui`（解释与呈现）单向依赖；排版层不被反馈校准回写。

## 5. 交互与数据需求要点

- 出生地选择器：省份下拉（宽度约 112–130px）+ 城市下拉（约 180px，随省份联动过滤）；城市项显示 `城市名（经度°E）`；下方保留自定义经度输入框与"应用/清除"。
- 城市表要求：城市名唯一；同经度接近的城市距离 ≥0.15° 偏差窗口内不得误匹配旧值（`cityNameOf` 取首个命中，选址时已规避相邻城市经度重合）。
- 精批卡结构：`总纲/分段/开运 tips` 三段式；分段标题如「一、日主与用神」；catNote 区块（`🎯 本题问事 · 专断`）仅在类别存在时渲染。

## 7. 与参考项目 `D:\Java\GitHub\xuanshu`（旧版单页）对比结论

| 维度 | 旧版 `xuanshu` | 本仓库 `xuanshu-z` | 本仓库优势 / 结论 |
|---|---|---|---|
| 工程结构 | packages（core/answer/kb/intake…）+ 单 web App | 同构 monorepo + web/desktop/mobile 三壳 | 多端复用；构建产物 7 级 manualChunks 分包 |
| 白话层 | `answer/plain/*`：facts 表+逐行 `refs` 归因 | `core/arts/jingpi.ts`：纯函数分段白话+`ruleId` 五级角标+术语旁路 | 归因思想保留并升级；新增"批注/白话同源"约束与空值泄漏巡检，旧版无此护栏 |
| 排盘确定性 | configHash + 纯函数 | 一致并强化（configHash 16 位指纹、缺时辰降级表） | 持平；本版补齐降级阻断规则 |
| 真太阳时 | 仅有少量城市经度 | 190 城 + 省份筛选 + 输入区/时间条/设置三入口联动 | 覆盖度与交互明显增强（本轮） |
| 测试基线 | 单包用例 | mono 全量 148 用例 + 校准/引用契约/审计三层 | 护栏更完整 |

结论：**以本仓库为准**。参考项目凡与本仓库设计冲突之处（引用归因粒度、白话组织方式、城市表结构），一律按本仓库既有约定执行；后续演进只在本仓库进行。
